# Java Programming Practical File — MCA 1st Semester (GGV, Bilaspur)

All source files and practice files (`Test_*`) are placed together in the `codes/` directory (each commented with its question number, statement, and inline explanations), and output screenshots are in `screenshots/`.

## Directory Structure

- `codes/` — All 29 reference source files (`q1`–`q21`) and 29 `Test_q*` practice files in a single folder:
  - `q1.java` (Q01: Find the Largest Element in an Array)
  - `q2.java` (Q02: Student Class with Constructors and Methods)
  - `q3.java` (Q03: Constructor Overloading and the `this` Keyword)
  - `q4.java` (Q04: Method Overloading / Compile-Time Polymorphism)
  - `q5.java` (Q05: Method Overriding Using Inheritance and `super`)
  - `q6.java` (Q06: Abstract Class and its Implementation)
  - `q7.java` (Q07: Interface and Multiple Implementation Classes)
  - `q8.java` (Q08: Exception Handling Using `try`, `catch`, and `finally`)
  - `q9.java` (Q09: User-Defined Exception Using `throw` and `throws`)
  - `q10.java` (Q10: Creating Threads Using `Thread` and `Runnable`)
  - `q11.java` (Q11: Swing GUI and Button Click Event)
  - `q12.java` (Q12: Producer-Consumer Synchronization)
  - `q13.java` (Q13: Multithreading & Thread Pool Management)
  - `q14.java` (Q14: JDBC Connectivity - MySQL CRUD Operations)
  - `q15.java` (Q15: Retrieve Host Name and IP Address Using `InetAddress`)
  - `q16_server.java`, `q16_client.java` (Q16: TCP Client and Server Communication Using Sockets)
  - `q17.java` (Q17: Connect Java to a Database Using JDBC)
  - `q18.jsp` (Q18: Display a Welcome Message Using JSP)
  - `q19.jsp` (Q19: Calculate the Sum of Two Numbers Using JSP)
  - `q20.html`, `q20.java` (Q20: Student Registration Form Using a Servlet)
  - `q21_schema.sql`, `q21_DBUtil.java`, `q21_RegisterServlet.java`, `q21_LoginServlet.java`, `q21_register.jsp`, `q21_login.jsp`, `q21_welcome.jsp` (Q21: Login & Registration App)
  - `Test_q*` — Practice/test version of each of the 29 files above, containing only the question comment and `TODO` marker
- `screenshots/` — Output screenshots named by question (`Q01_...png` through `Q21_...png`)
